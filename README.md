# TOKYO_RE-HOME
A furniture exchange platform for international students in Tokyo
### Please update your code under your number's branch


**TOKYO RE:HOME** is a student-to-student furniture exchange platform designed to help international students in Tokyo buy, sell, donate, and reuse second-hand furniture.

Our goal is to reduce the financial and logistical difficulties of furniture disposal and acquisition while promoting sustainability and resource reuse.

## Project Goals

- Build a user-friendly web application for international students in Tokyo.
- Provide a convenient platform for buying, selling, and donating furniture.
- Help students find available furniture nearby.
- Support communication and reservations between users.
- Encourage sustainable furniture reuse and reduce unnecessary waste.

## Key Features

- **User Authentication:** Secure registration, login, and user profiles.
- **Furniture Listings:** Create, edit, and manage furniture listings with images, descriptions, and prices.
- **Map-Based Search:** Discover furniture available near the user's preferred location.
- **Bundle Listings:** List multiple furniture items together.
- **Future Reservations:** Allow users to reserve furniture for future pickup dates.
- **User Messaging:** Enable direct communication between buyers and sellers.
